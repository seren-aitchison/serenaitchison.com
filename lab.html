Computational Lab · interactive

Explore the science yourself.

Ten working tools, not screenshots. Six of them query public scientific APIs live from your browser, so you are looking at current data. Nothing you do here is uploaded, stored or tracked.

Pharmacogenomics explorer Diplotype to phenotype Variant to protein VCF normalisation Read quality control Coverage audit Population frequencies Molecular explorer Interaction networks Statistics studio
Educational tools. These are built for exploring methods and public data. Nothing here is clinical advice, a diagnostic result, or a basis for any decision about medicines.

01 · Pharmacogenomics explorer

Variant annotation from Ensembl, allele function and drug association from CPIC.

ReadyThe project
Variant

Live lookup against the Ensembl REST API (GRCh38). The allele function and drug columns are curated from CPIC.

02 · Diplotype to phenotype

The CPIC assignment framework: activity scores and function categories, worked through for seven pharmacogenes.

Local computationThe method

03 · Variant to protein

Map a variant onto its residue, in the real translated sequence, and check the reference base agrees.

ReadyThe project

Runs VEP, picks the canonical protein-coding consequence, then fetches that transcript's translation and verifies the reference residue rather than assuming it.

04 · VCF normalisation

Split multi-allelic records, trim shared bases, and left-align indels against the real reference.

ReadyThe method

Reference sequence is fetched from Ensembl on GRCh38. Paste your own lines in the form CHROM POS ID REF ALT — nothing is uploaded anywhere.

05 · Read quality control

FASTQ parsing, Phred decoding and the diagnostics that decide whether a run is usable.

Local computationThe method

Scenario reads are simulated from a seeded generator so each pattern reproduces. Pasted reads are analysed identically and never leave the page.

06 · Pharmacogene coverage audit

Choose what a panel assays, then see what it misses — and for whom.

ReadyThe proposal
Alleles this panel assays

Frequencies come from a dated gnomAD snapshot so the tool is instant. Re-fetch to check it against Ensembl today — that query is slow, around half a minute per variant.

07 · Population frequency explorer

Allele frequencies across gnomAD population groups, fetched live.

ReadyThe project

Population labels are broad continental groupings. A frequency is not a risk, and these labels do not describe any individual.

08 · Molecular explorer

Structures in 3D with descriptors and drug-likeness rules, from PubChem.

ReadyThe proposal

Descriptors are PubChem's computed properties. Rule filters are heuristics for oral bioavailability, not predictions of activity.

09 · Protein interaction network

Build a network around a protein, then watch the hubs move as you raise the confidence threshold.

ReadyThe proposal

10 · Statistics studio

Manhattan and QQ plots, and expression fold changes, computed in the page.

Local computationThe project

GWAS data here is simulated, as in the source projects. The expression values are the illustrative dataset from the differential expression workflow.

How these are built

No framework, no build step.

Every tool is plain ES modules, SVG and canvas. Network requests go straight to the public APIs from your browser. The force layout, the plots and the statistics are implemented here rather than pulled from a charting library, because the point is to show the working.
