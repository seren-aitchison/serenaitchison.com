Methods, and how they fail.

A working reference for the methods I use. Each entry covers the problem it solves, the idea behind it, the assumptions it makes, the ways it breaks, and how to read its output honestly. The failure modes are the part I find most worth writing down — they are what separates using a method from understanding it.

Why this exists

Knowing when not to trust a method.

Any of these can be run from a library call in one line. The part that takes time to learn is recognising the situation where the output will be confidently wrong — a UMAP distance read as a measurement, a hazard ratio from crossing survival curves, a lead SNP treated as causal. That is what this library is for.
