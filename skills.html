What production work taught me.

Most bioinformatics graduates have written analysis code. Fewer have had to keep a system running for other people. These are the specific things that came from doing the second.

01

Trust boundaries

ForgeLab grades code submitted by the person being graded. Anything the browser claims has to be re-established on the server, under a permission model that assumes the submitted code is hostile.

Node permission model · process isolation · bounded runtime

02

Shared architecture

Gradify runs 30+ sites from one kit. The rule that makes that survivable is that sites consume the kit and never fork it, so a fix lands everywhere at once.

ES modules · shared design system · no build step

03

Data that outlives the code

Version-controlled migrations, row-level security and a schema designed to be queried by someone who did not write it.

PostgreSQL · migrations · row-level security
